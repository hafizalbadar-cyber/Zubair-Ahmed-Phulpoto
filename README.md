# Hafiz Zubair Ahmed Phulpoto - Portfolio (React + Vite)

```
npm install
npm run dev        # opens at http://localhost:5173 (also on your phone via the Network URL)
npm run build      # production files in /dist
```
- All text, phone and links: `src/data.js`
- Styles: `src/styles.css`   Photos: `public/images`
- Deploy: upload the `dist` folder to Netlify, Vercel, GitHub Pages or any host.
